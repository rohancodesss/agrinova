🌿 AgriNova — a farm that texts you back

Open-source smart crop protection and irrigation for small farmers, built with an iCE40 FPGA, an Arduino UNO and a Telegram bot. Total parts cost about ₹2,500.

View on GitHub Download binaries

What it does

  • 🔒 Intruder detection in hardware — an IR sensor wired to FPGA logic reacts in microseconds; your phone gets an alert, a photo (~2 s) and a video, and a mist burst deters the animal.
  • 💧 Closed-loop irrigation — sprays when the soil is dry, stops the moment the target moisture is reached.
  • 🌧 Weather-aware — checks the forecast (wttr.in) and skips watering when rain is coming.
  • 🚨 Tamper alarm — a CRITICAL alert if the camera is forcefully removed mid-recording.
  • 📊 Data — every reading logged; 24-hour graphs and daily summaries in chat.
  • 🌐 Telugu support — alerts in తెలుగు or Telugu in English letters, chosen with /lang.

Why an FPGA?

The safety-critical detection path is pure hardware: synchroniser → edge detector → hardware cooldown → UART. It cannot crash, needs no OS, and keeps watching even if every computer in the system goes down.
